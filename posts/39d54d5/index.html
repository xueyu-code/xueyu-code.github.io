本文档包含IGC驱动的各种流程图，可以通过Mermaid渲染为SVG格式。

1. IGC驱动主要代码流程图 

graph TD
    A[模块加载 igc_init_module] --> B[PCI驱动注册 pci_register_driver]
    B --> C[设备探测 igc_probe]
    
    C --> D[PCI设备初始化]
    D --> D1[pci_enable_device_mem]
    D --> D2[dma_set_mask_and_coherent]
    D --> D3[pci_request_mem_regions]
    
    D --> E[网络设备分配 alloc_etherdev_mq]
    E --> F[软件初始化 igc_sw_init]
    
    F --> F1[设置默认环大小]
    F --> F2[初始化工作队列]
    F --> F3[分配MSI-X向量]
    F --> F4[设置网络设备特性]
    
    F --> G[硬件初始化]
    G --> G1[igc_reset - 硬件重置]
    G --> G2[igc_get_hw_control - 获取硬件控制]
    G --> G3[igc_ptp_init - PTP初始化]
    
    G --> H[注册网络设备 register_netdev]
    
    H --> I[设备就绪]
    
    I --> J[网络接口启动 igc_open]
    J --> J1[igc_setup_all_tx_resources]
    J --> J2[igc_setup_all_rx_resources]
    J --> J3[igc_request_irq]
    J --> J4[igc_up]
    
    J4 --> K[设备配置 igc_configure]
    K --> K1[igc_configure_tx - 配置发送]
    K --> K2[igc_configure_rx - 配置接收]
    K --> K3[igc_configure_msix - 配置中断]
    
    K --> L[启用NAPI napi_enable]
    L --> M[启用中断 igc_irq_enable]
    M --> N[启动发送队列 netif_tx_start_all_queues]
    N --> O[启动看门狗定时器]
    
    O --> P[设备运行状态]
    
    P --> Q[数据包发送路径]
    Q --> Q1[igc_xmit_frame]
    Q1 --> Q2[igc_tx_queue_mapping - 选择队列]
    Q2 --> Q3[igc_xmit_frame_ring]
    Q3 --> Q4[检查描述符可用性]
    Q4 --> Q5[处理TSO/校验和卸载]
    Q5 --> Q6[设置VLAN标签]
    Q6 --> Q7[处理时间戳]
    Q7 --> Q8[映射DMA缓冲区]
    Q8 --> Q9[设置TX描述符]
    Q9 --> Q10[更新硬件尾指针]
    
    P --> R[数据包接收路径]
    R --> R1[硬件中断]
    R1 --> R2[igc_intr_msi - MSI中断处理]
    R2 --> R3[napi_schedule - 调度NAPI]
    R3 --> R4[igc_poll - NAPI轮询]
    R4 --> R5[igc_clean_tx_irq - 清理TX完成]
    R4 --> R6[igc_clean_rx_irq - 处理RX]
    R6 --> R7[读取RX描述符]
    R7 --> R8[分配新RX缓冲区]
    R8 --> R9[处理校验和]
    R9 --> R10[处理VLAN标签]
    R10 --> R11[构建skb]
    R11 --> R12[netif_receive_skb]
    
    P --> S[高级特性]
    S --> S1[TSN支持 igc_tsn.c]
    S --> S2[PTP时间同步 igc_ptp.c]
    S --> S3[XDP支持 igc_xdp.c]
    S --> S4[硬件诊断 igc_diag.c]
    
    P --> T[设备关闭 igc_close]
    T --> T1[igc_down]
    T --> T2[igc_free_irq]
    T --> T3[igc_free_all_tx_resources]
    T --> T4[igc_free_all_rx_resources]

3. IGC驱动数据包处理时序图 

sequenceDiagram
    participant App as 应用程序
    participant Kernel as 内核网络栈
    participant IGC as IGC驱动
    participant HW as I225硬件
    
    Note over App,HW: 数据包发送流程
    
    App->>Kernel: send()/sendto()
    Kernel->>Kernel: 协议栈处理
    Kernel->>IGC: ndo_start_xmit()
    
    IGC->>IGC: igc_xmit_frame()
    IGC->>IGC: igc_tx_queue_mapping()
    IGC->>IGC: igc_xmit_frame_ring()
    
    Note over IGC: 检查描述符可用性
    IGC->>IGC: 处理TSO/校验和卸载
    IGC->>IGC: 设置VLAN标签
    IGC->>IGC: 处理时间戳
    IGC->>IGC: 映射DMA缓冲区
    IGC->>IGC: 设置TX描述符
    
    IGC->>HW: 更新硬件尾指针
    HW->>HW: DMA传输数据
    HW->>HW: 发送到网络
    
    Note over App,HW: 数据包接收流程
    
    HW->>HW: 接收网络数据
    HW->>HW: DMA写入内存
    HW->>IGC: 产生中断
    
    IGC->>IGC: igc_intr_msi()
    IGC->>IGC: napi_schedule()
    
    Note over IGC: NAPI轮询开始
    IGC->>IGC: igc_poll()
    IGC->>IGC: igc_clean_tx_irq()
    
    Note over IGC: 清理已完成的TX
    IGC->>IGC: igc_clean_rx_irq()
    
    loop 处理多个RX数据包
        IGC->>IGC: 读取RX描述符
        IGC->>IGC: 检查数据包状态
        IGC->>IGC: 分配新RX缓冲区
        IGC->>IGC: 处理校验和
        IGC->>IGC: 处理VLAN标签
        IGC->>IGC: 处理时间戳
        IGC->>IGC: 构建sk_buff
        IGC->>Kernel: netif_receive_skb()
    end
    
    Note over IGC: 如果还有工作继续轮询
    IGC->>IGC: napi_complete_done()
    IGC->>HW: 重新启用中断
    
    Kernel->>Kernel: 协议栈处理
    Kernel->>App: recv()/recvfrom()

4. IGC驱动诊断功能流程图 

graph TD
    A[用户执行 ethtool -t eth0] --> B{测试模式}

    B -->|offline| C[离线测试模式]
    B -->|online| D[在线测试模式]

    C --> C1[igc_ethtool_diag_test]
    C1 --> C2[设置 __IGC_TESTING 状态]
    C2 --> C3[如果接口运行中则关闭]

    C3 --> E[链路测试 igc_link_test]
    E --> E1[检查自动协商状态]
    E1 --> E2[等待5秒完成协商]
    E2 --> E3[调用 igc_has_link]
    E3 --> E4{链路是否建立}
    E4 -->|是| E5[测试通过]
    E4 -->|否| E6[测试失败]

    E --> F[寄存器测试 igc_reg_test]
    F --> F1[STATUS寄存器特殊测试]
    F1 --> F2[遍历寄存器测试表]
    F2 --> F3{测试类型}

    F3 -->|PATTERN_TEST| G[模式测试]
    F3 -->|SET_READ_TEST| H[设置读取测试]
    F3 -->|TABLE32_TEST| I[32位表测试]
    F3 -->|TABLE64_TEST_LO| J[64位表低位测试]
    F3 -->|TABLE64_TEST_HI| K[64位表高位测试]

    G --> G1[写入测试模式]
    G1 --> G2[0x5A5A5A5A]
    G1 --> G3[0xA5A5A5A5]
    G1 --> G4[0x00000000]
    G1 --> G5[0xFFFFFFFF]
    G2 --> G6[读取并验证]
    G3 --> G6
    G4 --> G6
    G5 --> G6
    G6 --> G7[恢复原始值]

    H --> H1[写入指定值]
    H1 --> H2[读取并验证]
    H2 --> H3[恢复原始值]

    I --> I1[测试32位寄存器表]
    J --> J1[测试64位寄存器表低位]
    K --> K1[测试64位寄存器表高位]

    F --> L[EEPROM测试 igc_eeprom_test]
    L --> L1[调用 hw->nvm.ops.validate]
    L1 --> L2{校验和正确}
    L2 -->|是| L3[测试通过]
    L2 -->|否| L4[测试失败]

    F --> M[中断测试 - 未实现]
    F --> N[环回测试 - 未实现]

    C1 --> O[恢复接口状态]
    O --> P[清除 __IGC_TESTING 状态]
    P --> Q[返回测试结果]

    D --> D1[在线测试模式]
    D1 --> D2[只执行链路测试]
    D2 --> E

    subgraph "测试覆盖的寄存器"
        R1[流控制寄存器
FCAL, FCAH, FCT]
        R2[接收描述符寄存器
RDBAH, RDBAL, RDLEN, RDT]
        R3[发送描述符寄存器
TDBAH, TDBAL, TDLEN, TDT]
        R4[控制寄存器
RCTL, TCTL]
        R5[接收地址表
RA]
        R6[多播表
MTA]
    end

    subgraph "错误处理"
        ERR1[记录失败的寄存器地址]
        ERR2[输出详细错误信息]
        ERR3[设置测试失败标志]
        ERR4[恢复寄存器原始值]
    end

使用说明

这些流程图使用Mermaid语法编写，可以通过以下方式转换为SVG：

  1. 在线工具: 访问 https://mermaid.live/ 粘贴代码生成SVG
  2. VS Code插件: 安装Mermaid Preview插件
  3. 命令行工具: 使用mermaid-cli工具 
    1
2

    npm install -g @mermaid-js/mermaid-cli
mmdc -i flowchart.md -o flowchart.svg

流程图说明

  • 主要代码流程图: 展示从驱动加载到数据包处理的完整流程
  • 硬件抽象层架构图: 展示驱动的分层架构和模块关系
  • 数据包处理时序图: 详细展示发送和接收数据包的时序关系
  • 诊断功能流程图: 展示igc_diag.c实现的硬件诊断测试流程

这些图表有助于理解IGC驱动的整体架构和工作原理，特别是硬件诊断功能的实现细节。
